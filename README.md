# vt_check-IP

Учебный скрипт: проверяет репутацию IP-адреса или домена через бесплатный API VirusTotal (v3)
и выводит, сколько антивирусов считают его опасным, подозрительным или чистым.

## Установка

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
```

Ключ API (берётся в профиле на virustotal.com) сохраняется в переменную окружения, а не в код:

```powershell
setx VT_API_KEY "ваш_ключ"
```

После `setx` терминал нужно перезапустить.

## Запуск

```powershell
.\venv\Scripts\python.exe vt_check.py
```

Пример:

```
Введите IP или домен: 8.8.8.8

Результат для 8.8.8.8:
  Опасно:        0
  Подозрительно: 0
  Безопасно:     53
  Нет данных:    38
Вердикт: угроз не найдено
```

## Ограничения

- Бесплатный ключ — 4 запроса в минуту, только для личного некоммерческого использования.
- Скрипт только читает готовый отчёт и ничего не загружает в VirusTotal.
